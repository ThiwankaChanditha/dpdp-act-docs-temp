# WSO2 DPDP Accelerator documentation

This repository contains the Docusaurus source for the WSO2 DPDP Accelerator
documentation site.

## Local development

```bash
pnpm install
pnpm start
```

The local site is available at `http://localhost:3000/dpdp-act-docs-temp/`.

Build the static site with:

```bash
pnpm build
```

The production site is deployed to GitHub Pages by the workflow in
`.github/workflows/deploy.yml`.
